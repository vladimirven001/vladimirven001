## Projects

### [openswe](https://github.com/vladimirven001/openswe)
openswe is a TUI app for managing AI agents. openswe connects to github, pulls open issues, and starts working on them in dedicated worktrees.  
openswe works with opencode, codex, and claude code, and is built with tmux and opentui.

### [lessnotes](https://github.com/vladimirven001/codejam14-lessnotes)  
lessnotes is a RAG app targeted to students. It allows students to import their school notes, and ask questions about them to Llama 3.1.  
Built with [Langchain](https://www.langchain.com/) and [Ollama](https://ollama.com/)  

### [WatchMatch](https://github.com/vladimirven001/WatchMatch)  
WatchMatch allows you find watches that look like the Rolex you want, but at a budget you can afford.  
Built with [BeautifulSoup4](https://pypi.org/project/beautifulsoup4/) and [sklearn](https://scikit-learn.org/stable/); [Streamlit](https://streamlit.io/) for the frontend.
